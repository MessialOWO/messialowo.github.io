# 达高中墙Board

> 达州市高级中学（达高中）非官方网站 —— 学生自建的留言板、班级期刊与画廊

**网站地址：<https://messialowo.github.io/>**

## 这是什么

一个由达州市高级中学在校学生自己搭建的网站，用来放同学们写的东西：

- **[留言板](https://messialowo.github.io/guestbook.html)** — 分 11 个区（学习、新闻、作品、失物招领、游戏、二次元、内娱、学校吐槽、意见建议、其他），支持标签、搜索、配图与音视频
- **[班级期刊](https://messialowo.github.io/journal.html)** — 高 2025 级 1 班的班级期刊，按期刊期号 → 专区 → 板块 → 文章组织
- **[画廊](https://messialowo.github.io/gallery.html)** — 同学们的作品图片
- **[关于学校](https://messialowo.github.io/about-school.html)** — 学校历史、三个校区介绍
- **[常见问题](https://messialowo.github.io/faq.html)** — 关于学校和本站的常见疑问

## 说明

本站与学校官方无隶属关系，不代表学校立场。
招生、收费等正式信息请以学校官方渠道为准。

## 技术

静态页面托管在 GitHub Pages，数据与文件存储使用 Supabase，
接口经由 Cloudflare Pages 中转（解决国内直连不稳的问题）。
