本站的技术说明

本站使用 GitHub Pages 免费托管，网址 messialowo.github.io，源码公开在 GitHub 上。数据存放在 Supabase 的免费数据库里，图片存放在它的对象存储里。

因为国内直连 Supabase 时常被干扰，本站加了一层免费中转，所以你在国内打开也能正常看到内容，不需要任何设置。

网站由学生自己维护，服务器额度、域名等全部自费，没有任何广告和收费。

搭建本站用到的开源项目

  • GitHub Pages静态站点托管
  • Supabase数据库、用户鉴权、对象存储
  • supabase-js前端数据库客户端（MIT）
  • Deno Deploy接口中转服务
  • Render备用中转服务
  • GitHub Actions定时任务与自动部署
  • Google Sans标题与界面字体
  • Liquid Glass界面折射效果参考（MIT）

以上项目各自遵循其开源许可，本站仅作学习与非商业用途使用。
